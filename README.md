# Ansible Labs Practice

This repository contains my hands-on **Ansible labs** created to practice and strengthen automation and configuration management concepts for DevOps engineering.

## 🧩 Overview
Ansible is an open-source automation tool used for configuration management, application deployment, and orchestration.  
These labs include various real-world use cases such as managing inventories, using variables, conditionals, roles, and encrypting sensitive data using Ansible Vault.

## 🚀 Labs Included
- **Lab 1:** Inventory and Basic Playbook  
- **Lab 2:** Variables and Templates  
- **Lab 3:** Loops and Handlers  
- **Lab 4:** Facts and Conditionals  
- **Lab 5:** Ansible Vault and Secrets Management  

Each `.yml` file represents a lab focused on a specific concept.
